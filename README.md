# Coffee Kiosk Project
Kosta 286기 1차 미니 프로젝트 (Java Mini Project)

---

## 📑 Project Overview
- **Project Name:** Coffee Kiosk
- **Team Members:** 김태휘, 이성민, 김재영, 이인영  
- **Project Description:**  
코로나 시대 이후 서비스업 및 관련 프렌차이즈 등의 업체에서 급증한 키오스크 수요를 반영하여 실제 사용 내용을 기반으로 판매자와 구매자 사이에서 커피 판매 서비스를 제공하는 키오스크 시스템.
